# Apex Strike

NFT-gated Contra-style run-and-gun for **Apex Huntress** holders on Cronos.

**Live:** https://apex-strike-production.up.railway.app

## v0.4

- 5 progressive levels
- Boss fight on Level 5
- Improved procedural art (player, enemies, platforms)
- Power-ups: Health, Spread, Rapid, Laser
- Enemy types: Walker, Flyer, Tank, Boss
- Screen shake, particles, hit flash
- Keyboard + Gamepad + Mobile touch
- Dev Mode bypass for testing

## Levels
1. Neon Streets
2. Industrial Rise
3. Sky Rail
4. Core Access
5. Apex Throne (Boss)

## Controls
| Input | Move | Jump | Shoot |
|-------|------|------|-------|
| Keyboard | A/D | W | Space |
| Gamepad | Stick / D-Pad | A | X / RT |
| Mobile | On-screen | JUMP | FIRE |
